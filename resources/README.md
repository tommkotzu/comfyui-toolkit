# Resources

Links and notes I've collected. Add new entries to the matching section.

## ComfyUI

- [ComfyUI](https://github.com/comfyanonymous/ComfyUI): the core app
- [Comfy Desktop](https://www.comfy.org/download): desktop app (AppImage on Linux)
- [ComfyUI-Manager](https://github.com/Comfy-Org/ComfyUI-Manager): install and update node packs from inside ComfyUI

## Node packs I use

| Pack | What for |
|---|---|
| [gokayfem/ComfyUI_VLM_nodes](https://github.com/gokayfem/ComfyUI_VLM_nodes) | Vision-language models (Moondream 3.1, Florence-2, Qwen-VL …), detection, detection rendering |
| [systms-ai/TimeSlice-Nodes](https://github.com/systms-ai/TimeSlice-Nodes) | Time-slice / slit-scan video effect |
| [kijai/ComfyUI-moondream](https://github.com/kijai/ComfyUI-moondream) | Older Moondream nodes; the reference for the HUD-box overlay look |
